# Amethyst — GitHub Pages site

Static pages used for the Homepage, Privacy Policy, and Terms of Service links in the
Google Cloud OAuth consent screen for the personal Android app **Amethyst**.

Repository: https://github.com/BoredRohan37/Amethystpages

Files:

- `index.html` — homepage
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `README.md` — this file

There is no build step. Every page is plain HTML5 with inline CSS and works when
opened directly from disk.

## Before you publish

1. Replace the placeholder email `youremail@example.com` in `privacy.html` and
   `terms.html` with your real address (and remove the "placeholder" note).
2. Update the "Last updated" date in `privacy.html` and `terms.html` to the day you
   publish them.
